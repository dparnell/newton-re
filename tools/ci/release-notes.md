Newton OS (the MessagePad 2x00's NewtonOS 2.1, reconstructed) for:

| archive | host |
|---|---|
| `newton-windows-x86_64.zip` | Windows 10/11, x86-64 |
| `newton-linux-x86_64.tar.gz` | Linux, x86-64 (glibc 2.35 or later; X11) |
| `newton-remarkable-aarch64.tar.gz` | reMarkable Paper Pro with xovi and AppLoad (v0.6.0 or later) |

Each has a README.txt saying how to run it.  No ROM image is needed: newton
boots from `romsrc-objects.bin`, built from the repository's `romsrc/`.
