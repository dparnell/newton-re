# The NewtonScript grammar

Generated by `tools/newton-rom/analysis/nsgrammar.py build/MP2100D --doc docs/frames/grammar.md`
from the ROM's `yyrule` table (0x00376664): the rules of the Berkeley yacc grammar
`TCompiler::Parser` (0x002fd9b0) parses, in yacc's own notation (`$$n` is a
mid-rule action).  `tokenX` are the lexer's tokens (`yyname`, 0x00376180); the
reserved words, in the lexer's table, are:

    and begin break by call constant deeply do div else end exists for foreach func global if in inherited local loop mod native not onexception or repeat return self then to try until while with

Precedence and associativity are in the tables, not the rules: `:=` is
right-associative and lowest, then `and`/`or`, `not`, the comparisons,
`&`/`&&`, `+`/`-`, `*`/`/`/`div`/`mod`, `<<`/`>>`, unary `-`, `exists`,
then `.`/`[]`/`:` (the operator table of the NewtonScript Reference).
